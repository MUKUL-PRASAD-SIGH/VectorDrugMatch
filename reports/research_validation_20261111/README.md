# VectorDrugMatch Research Validation

This directory contains the five-seed computational evaluation report.

- `research_report.md`: research findings and limitations.
- `five_seed_performance.csv`: classification performance.
- `five_seed_ranking.csv`: ranking metrics.
- `five_seed_calibration.csv`: calibration metrics.
- `five_seed_error_analysis.csv`: error metrics.
- `figures/`: six generated evaluation visualizations.

All results are conditional on the evaluated datasets and saved split.
Sampled negatives are not confirmed non-interactions. This report
does not establish clinical validity or deployment readiness.
